# アプリで使える練習

提案は、ここにある練習に落とし込む。「何を・何回（または何分）・どんな目標で」まで書く。

## タイマー（フルソルブ）

- 画面上部の「タイマー」。WCA 方式のランダムなスクランブルで1回ずつ測る
- 設定で 15秒のインスペクションを使える
- 向いている使い方：ao12 を測る、ゆっくり止まらずに解く練習（タイムより「長い間」を減らすのが目標）

## 練習 → 手順練習

- OLL 57・PLL 21・F2L 41 のケースから1つ選び、その手順を何度も回して1回ごとの時間を測る
- 揃っていない状態から回してよい。前後の AUF（U）や、別の面での実行も正解になる
- ケースによっては別の手順を選べる（OLL 27ケース・PLL 18ケース）
- 目標の秒数を決めると、目標以内の回数と割合が出る
- 向いている使い方：遅い・忘れがちな手順を、目標秒数を決めて 20〜50回。例「PLL の Ja を目標 2.5秒で 30回、目標以内 8割まで」

## 練習 → ステップ練習

- Cross / F2L / OLL / PLL のどれか（またはランダム）について、その段階の直前の状態から始め、その段階だけを測る
- 向いている使い方：
  - Cross：インスペクションで最後まで計画してから回す。目標「8手以内・3秒以内」を 20回
  - F2L：止まらずに回す練習。1ペアごとの間を減らす
  - OLL / PLL：ケースの見分けから実行までを通して測る（認識の練習）

## 提案の例

- 「F2L の認識が 1ペアあたり平均 1.8秒。ステップ練習の F2L を 1日 10回、"回しながら次のペアを探す" を意識して、ゆっくりでよいので止まらずに回す」
- 「PLL の実行 TPS が 2.1 と低い。手順練習で今回出た Ra を目標 4秒で 30回」
- 「OLL の途中に毎回 1秒前後の間があり、2-look と見られる。まずはステップ練習の OLL で 2-look の継ぎ目を短くし、慣れたら、2-look の2回目でよく出る形から、手順練習で 1-look の OLL を少しずつ増やす」
