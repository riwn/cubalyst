# Phase 7 実装計画：ステップ練習（Cross / F2L / OLL / PLL）

## ゴール
各段階の直前状態のスクランブルが出題され、記録できる。

## 出題
- 段階はランダムに選ぶか、指定する
- 制約を満たすランダムな状態を、標準の向き（クロスD・最終層U）でピースを直接並べて作る
  - Cross：完全にランダムな状態（ランダムステートスクランブルをそのまま使う）
  - F2L：クロスの4エッジだけ完成、他のピース（D層の角・中層エッジ・最終層）はランダム
  - OLL：F2L完成、最終層の位置と向きがランダム
  - PLL：OLLまで完成、最終層の位置だけランダム
  - 角・エッジの置換の偶奇と、向きの合計（角は3の倍数、エッジは偶数）がそろうようにする
- クロス色に合わせてキューブ座標系へ写し（Phase 6と同じ持ち替え）、ソルバーの解の逆をスクランブルにする
- 完了条件：その段階が完了した時点で計測を止める（Cross＝クロス完成、F2L＝4スロット、OLL＝上面、PLL＝完成）
- 練習は完成状態から始める（揃っていなければ揃えるよう促す）

## 記録
- `mode=step`、`step` に段階名（cross / f2l / oll / pll）
- 段階の区切りも保存する（F2L練習なら f2l1〜f2l4 の時間がわかる）。開始状態はスクランブルから求める

## 画面（練習 → ステップ練習）
- 段階の選択（ランダム / Cross / F2L / OLL / PLL）、計測
- 段階ごとの回数・平均・ベスト・ao5（直近）
