# Phase 4 実装計画：統計・グラフ

## ゴール
推移・分布・段階別統計がフィルタ付きで表示される。

## データ
- `GET /api/solves?limit=0&include=splits&order=asc`＋フィルタで対象ソルブを取得し、フロントで集計する
  （ローカル専用・個人用で件数は数万程度までの想定。サーバー側の集計APIは不要）

## 画面（統計）
- フィルタ（1行）：モード、期間（全期間／7日／30日／90日／任意）、ケース（ケース練習）、段階（ステップ練習）
- ベスト記録：single / ao5 / ao12 のベストと現在値（数字のタイル。グラフにはしない）
- 推移グラフ：single（点）・ao5・ao12（線）。横軸はソルブ番号。ホバーで日時と3系列の値
  - 3系列なので凡例＋末尾の直接ラベル
- 分布グラフ：直近N件（N指定可、既定100）のヒストグラム。ビン幅は件数と範囲から自動（0.25s〜5s）。DNF件数は別記
- 段階別統計：Cross / F2L / OLL / PLL（F2Lはスロット別も表で）の平均時間・平均手数・全体に占める割合・TPS
  - 割合は100%の横積み棒1本、数値は表で併記
- 配色：dataviz の既定カテゴリ配色（slot 1〜4）を順番固定で使い、ライト／ダーク両方を定義

## 実装
- `recharts` を導入
- 集計関数（`web/src/solve/aggregate.ts`）：推移データ、ヒストグラムのビン、段階別平均。vitestでテスト
