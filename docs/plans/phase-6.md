# Phase 6 実装計画：ケース単発練習（OLL / PLL / F2L）

## ゴール
OLL / PLL / F2L のケースを選んで練習・記録できる。

## ケースのマスタ
- `web/src/cases/data.ts` を正とし、そこから `cases` テーブルのシード（マイグレーション `0004_cases.sql`）を生成する
  - 列：`id`（oll-1, pll-T, f2l-1 …）, `set`（OLL/PLL/F2L）, `name`, `alg`（標準手順）, `pattern`（画像生成用の54文字facelets）, `sort`
- 手順は「標準の向き」（上面＝最終層、下面＝クロス、F2LはFRスロット）で書く
- **手順の正しさをテストで検証する**
  - OLL：逆手順を当てるとF2Lは保たれ、上面だけが崩れる。57ケースがAUFを除いて互いに異なる
  - PLL：逆手順を当てるとOLLまで保たれる。21ケースが前後のAUFを除いて互いに異なる
  - F2L：41ケースは「FRの角とエッジの置き場所・向き」を数え上げて作り、手順は探索（R/U/F の基本手順の組み合わせ）で求める。
    逆手順を当てるとクロスと他の3スロットは保たれる
- `GET /api/cases` でマスタを返す

## 出題（スクランブル生成）
- 標準の向きの「ケースの状態」（ランダムな前後AUF付き）を作り、キューブ自身の座標系
  （GAN標準配色：白U・緑F）へ、クロス色に合わせた持ち替えで写す
  - 例：白クロス（既定）なら、最終層は黄＝キューブのD面
- その状態をソルバー（cubing.js の 3x3 ソルバー）で解き、その逆手順をスクランブルにする
  （ケース手順の逆をそのまま見せないので、ケースを覚えてしまうことがない）
- 完了条件：OLL＝F2L完成＋最終層の面が揃う、PLL＝完成、F2L＝4スロット完成（対象スロットが揃う）
- 練習はスクランブル前に完成状態である必要がある（揃っていなければ揃えるよう促す）

## 画面（練習）
- モード選択：フル / ケース / ステップ（ステップはPhase 7）
- ケース練習：セット（OLL/PLL/F2L）ごとにケース一覧（図つき）、複数選択（全選択・解除）、選んだ中からランダム出題
- 出題中はケース名を隠し、解き終えたらケース名と標準手順を表示
- ケース別の平均・回数と、苦手ケースのランキング（平均が遅い順）
