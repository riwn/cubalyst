# Phase 5 実装計画：ソルブ再生

## ゴール
履歴のソルブを段階ジャンプ付きで再生できる。

## 方針
- 詳細画面に再生プレイヤーを置く。3D表示は TwistyPlayer
  - setup：ソルブ開始時の状態（フルソルブは「完成状態に回転ログの逆手順」、ケース・ステップは「完成状態にスクランブル」）
  - alg：回転ログの全手
- **実際の回転タイミングどおりに再生する**ため、TwistyPlayer自身の再生機能は使わず、
  自前の時計（requestAnimationFrame）で「実時間 → TwistyPlayerのタイムライン位置」を毎フレーム設定する
  - 手 i は記録時刻 t_i から min(100ms, 次の手までの間隔) かけて回る（間の取り方を再現）
  - 写像は純粋関数（`replay-timeline.ts`）にしてテストする
- 操作：再生 / 一時停止、シークバー、速度（0.5x / 1x / 2x / 4x）、1手戻る / 1手進む、先頭 / 末尾
- タイムラインに段階の区切りを表示し、クリックでその段階の開始へジャンプ
- 現在の経過時間・手数・段階名を表示。キーボード：Space 再生/停止、←/→ コマ送り
